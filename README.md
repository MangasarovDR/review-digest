# Автодайджест отзывов

Мультиклиентский сервис мониторинга отзывов о бизнесе на Wildberries, Я.Картах, 2GIS и Google Maps. Собирает новые отзывы по нескольким источникам, считает динамику, отправляет дайджест и показывает состояние в дашборде.

## Как это устроено

- **Мультиисточниковый сбор** (`fetchers/`) — отдельный fetcher на каждую площадку (`wildberries.py`, `yandex_maps.py`, `dvgis.py`, `google_maps.py`, `vseinstrumenti.py`), общий интерфейс в `base.py`.
- **Пул прокси с учётом трафика** (`fetchers/proxy_pool.py`) — ротация прокси по площадкам с алертом при подходе к лимиту трафика.
- **Мультиклиентность** (`scripts/add_client.py`, `scripts/list_clients.py`) — сервис обслуживает нескольких клиентов из одной базы.
- **Ежедневный цикл** (`scripts/daily_update.py`) — сбор → расчёт дельты → уведомление.
- **Уведомления** (`app/notify.py`) — дайджест уходит клиенту напрямую.
- **Дашборд** (`app/main.py`, `templates/`) — веб-интерфейс для просмотра отзывов и управления источниками, PWA (`static/sw.js`).

## Стек

Python, FastAPI, SQLite, Docker.

## Что не в репозитории

`data/` — реальная база клиентов и собранных отзывов, не код, исключена из публикации вместе с `.env`.
